# GTA 6 Launch Week — Funniest AI Agent Mishap

Entry for the make.fun bounty "Funniest AI Agent Mishap: GTA 6 Launch Week".

`main.py` writes one sentence (at most 240 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`: the funniest true-to-life thing an AI
coding agent did while its human was busy playing GTA 6 on launch week.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
